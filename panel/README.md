# 横の欄（panel）

Claude Code の mod です。セッションを開くと、2か所に出ます。

- **入力欄の上**: 今日やること（番号つき、押すと取りかかる）、予定、ボタン（バックログ・ドメイン・履歴・✦ 何をする？）。最初に何か送ると1行にたたまれ、[メニュー] か `/menu` でまた開きます。
- **画面の横**: ドメインの一覧。ドメインごとに「最後にやったこと」と、開いている項目の数。ドメインを押すと項目が開き、項目を押すと操作が並びます（→ 取りかかる / ✓ 完了 / 💤 保留 / ⏰ 日付変更 / ✗ やめる）。選んだときだけセッションに届きます。「✦ ここで何をする？」でそのドメインの相談ができます。

## 使い方

試作なので、使うかどうかは自分で選びます。いつもの `start` の動きは変わりません。

```
bin/start --panel
```

画面の幅が足りないと横の欄は出ません（初回は 144 列ほど要ります）。そのときは `/panel` で開けます。

## しくみと安全のこと

- 読むのは `bin/menu --json` と `bin/menu --json --domains` だけ。ほかのプログラムは動かさず、このリポジトリのファイルも書き換えません。書き換えるのは、届いた文を読んだ AI です。
- 項目を送るときは、題名ではなく **id と置き場所**（ファイルと行）だけを送ります。題名に指示のような文が紛れていても、そのまま AI に届かないようにするためです。
- 🔒 の付いた項目は、端末以外の画面（スマホなど）では件数だけになります。
