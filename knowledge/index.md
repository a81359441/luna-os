# ナレッジ・マスター索引

このシステムが「何を知っているか」の全体台帳です。ドメインの詳細はここではなく、各ドメインの `index.md` にあります。ここは**どこに何があるかの案内板**であって、事実の置き場ではありません。

## 原則

- 検証済みの事実は `knowledge/domains/**` にのみ存在する。
- ドメインの主張には出典を付ける（`出典: domains/<domain>/<file>.md（見出し）`）。
- ナレッジベースに無いことは「情報がありません」と答える。
- 新しい知識はブランチ上の提案として出し、承認されてから真実になる。

## ドメイン目録

新しいドメインを追加したら、ここに次の形で1ブロック追加します（`add-domain` スキルが自動でやります）。

```markdown
### <ドメイン名>

- **場所**: `knowledge/domains/<slug>/`
- **索引**: `knowledge/domains/<slug>/index.md`
- **状態**: 稼働中 / 保留 / 提案
- **目的**: <一行>
- **主要な事実**: <索引を見れば分かる要点を2〜3行。詳細は書かない>
```

## 揮発するもの（Connections）

ここに取り込まないもの。日々の予定、未処理のToDo、チャットのスレッド、顧客データ、価格のように毎週変わる数字。これらは揮発する場所（`agenda.md`、外部ツール、ログ）に置いたまま、必要ならここから**案内だけ**します。

| 揮発データ | 置き場所 |
|---|---|
| 今日の予定 | `knowledge/domains/<personal>/agenda.md` |
| 横断のバックログ | `tasks/backlog.md` |
