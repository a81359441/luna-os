    What is LUNA

    LUNA とは

    犬の散歩につけるハーネスを思い浮かべてください。走り出しそうになっても、体をそっと支えて道を外れさせない。

    LUNA は、賢いけれど忘れっぽいAIにつける、そういう枠です。中のAIが新しいものに入れ替わっても、枠とあなたの記録はそのまま残ります。

    • 忘れない大事なことはファイルに残ります。次に開いたとき、AIはそれを読んでから話します。
    • 嘘をつかない記録にないことは「わかりません」と言います。思い出したふりで作り話をしません。
    • 決めるのはあなたAIが新しく覚えることは、あなたが OK を出してはじめて記録になります。
    • 毎回ブリーフから開くたびに、今日やること、締切、忘れてはいけないことを最初に教えてくれます。

    仕事、暮らし、発信、事業。分野ごとに引き出しを分けて、使うほどあなたの文脈が貯まります。中身はあなたの Mac と、あなただけが開ける金庫（GitHub）に置かれます。AIの名前はセットアップで自由に決められます。

    Before you start

    用意するもの

    • Mac新しくても古くても大丈夫です
    • Claude の有料プラン月額の「Pro」以上。claude.ai で申し込めます
    • メールアドレスGitHub（ギットハブ）の登録に使います
    • Mac のパスワード途中で何度か聞かれます

    Three tips

    最初に知っておく3つのこと

    このページでは「ターミナル」という、文字で Mac に指示を出す画面を使います。コツは3つだけです。

    1. 1

      コマンドは、コピーして貼り付ける

      自分で打たなくて大丈夫です。各コマンドの右にある「コピー」を押して、ターミナルに貼り付けます。

      ⌘ command＋V で貼り付け → return
    2. 2

      自分で打つときは「英数」で

      日本語入力のままだと、Mac は指示を理解できません。全角スペースもエラーのもとです。

      打つ前に 英数 を押す
    3. 3

      パスワードは、打っても何も出ない

      Password: と出たら Mac のパスワードを打って return。●●● すら出ませんが、ちゃんと入っています。

    Setup

    6つのステップ

    終わったステップに印をつけておくと、次に開いたときに続きがわかります。

    STEP 01 · 5分

    ターミナルのアプリを入れる

    iTerm2（アイターム・ツー）
    1. iterm2.com を開き、Download を押す
    2. 「ダウンロード」フォルダにできた iTerm を、「アプリケーション」フォルダにドラッグ
    3. 「アプリケーション」の iTerm をダブルクリック
    4. 下のような確認が出たら 「開く」

    次から iTerm を開くには：⌘ command＋スペース → iterm → return

    STEP 02 · 15〜20分

    Homebrew（ホームブルー）を入れる

    道具の App Store

    Homebrew は、AI を動かすのに必要な道具をまとめて入れてくれる仕組みです。スマホの「App Store」のようなものです。次の1行をコピーして、iTerm に貼り付けて return。

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    1. Password: と出たら、Mac のパスワードを打って return
    2. Press RETURN/ENTER to continue と出たら return
    3. 文字がたくさん流れるので、10〜20分待つ。「コマンドライン・デベロッパ・ツール」の窓が出たら 「インストール」
    ここが一番大事です。 Next steps: の下に出た行を、上から1行ずつコピーして貼り付け、return。画面に出たとおりでかまいません。多くの Mac では次の2行と同じです。
    echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
    eval "$(/opt/homebrew/bin/brew shellenv)"

    できたか確かめる：

    brew --version
    Homebrew 4.x.x のように数字が出れば成功です。
    STEP 03 · 10分

    GitHub（ギットハブ）に登録する

    あなたのAIの金庫

    GitHub は、あなたのAIの中身（メモや記録）を預けておくインターネット上の金庫です。Mac が壊れても消えず、あなた以外には見えません。

    3-1アカウントを作る（無料）

    github.com/signup で登録し、届いたメールのコードを入れて完了します。

    3-2Mac から GitHub につなぐ

    brew install gh
    gh auth login

    英語で質問が出ます。矢印キー ↑↓ で選んで return。

    画面に出る質問意味選ぶもの
    Where do you use GitHub?どこの GitHub？GitHub.com
    What is your preferred protocol…?つなぎ方は？HTTPS
    Authenticate Git with your GitHub credentials?この Mac でもログインしておく？Y を打って return
    How would you like to authenticate…?どうやってログインする？Login with a web browser
    ✓ Logged in as あなたのユーザー名 と出れば成功です。
    STEP 04 · 3分

    Claude Code を入れる

    AIの本体
    curl -fsSL https://claude.ai/install.sh | bash
    終わったら、iTerm を一度完全に終了（⌘ command＋Q）して、開き直してください。新しく入れたものを Mac に気づかせるためです。
    claude --version
    2.x.x (Claude Code) のように数字が出れば成功です。
    STEP 05 · 2分

    あなた専用のAIを作る

    ひな形をコピー

    3行を、1行ずつ貼り付けて return。

    mkdir -p ~/Claude && cd ~/Claude
    gh repo create my-ai --private --template a81359441/luna-os --clone
    cd my-ai
    STEP 06 · 10分

    はじめて話しかける

    ここから日本語
    claude "setup"

    最初の1回だけ、英語でいくつか聞かれます。

    画面に出るもの意味すること
    Choose the text style…画面の色合い好きなものを選んで return
    Select login methodログイン方法Claude account with subscription
    （ブラウザが開く）Claude にログインいつものアカウントで「承認」
    Do you trust the files in this folder?このフォルダを信用する？Yes, proceed

    ここを抜けると、AIが日本語で話しはじめます。名前、あなたの呼び方、いま頭を使っていること。1つずつ聞かれるので、普通に日本語で答えてください。AIの名前を決めると、その名前で呼び出せるようにAIが設定してくれます。途中で「実行してよいか」と英語で聞かれたら、Yes を選んでください。

    お疲れさまでした

    次からは、iTerm を開いて、AIの名前（英小文字）を打つだけです。たとえば名前がルナなら：

    luna

    話が一段落したら「締めて」。AIがその日の内容を記録します。
    終わるときは control＋C を2回。

    ときどき「ログインして」と言われたら（Please run /login など。故障ではありません）

    1. 入力欄に /login と打って return（選択肢がもう出ていれば飛ばす）
    2. 3つの選択肢から 1番の Claude account with subscription を選ぶ。ほかの2つは選ばない
    3. ブラウザが開くので、いつものアカウントでログインして「承認」
    4. iTerm に戻る（⌘ command＋tab）。そのまま話の続きができます

    Troubleshooting

    うまくいかないとき

    まず、iTerm を完全に終了して（⌘ command＋Q）開き直してください。これだけで直ることがとても多いです。

    画面に出た言葉よくある原因直し方
    command not found: brewステップ2の最後の行を貼り忘れたその行を貼り付けて、iTerm を開き直す
    command not found: claude やAIの名前Mac が新しい道具にまだ気づいていない下の1行を貼り付けて、開き直す
    プランがない、と言われるClaude が無料プランのままclaude.ai で Pro 以上にして、入力欄で /login
    反応しない、変な文字が出る日本語入力のまま打った英数 を押して、コピー＆貼り付けでやり直す
    echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc

    ステップ6まで進めていれば、エラーをAIに貼り付けて「これは何？」と聞けば教えてくれます。その前なら、画面のスクリーンショット（⌘＋shift＋4）を、このページをくれた人に送ってください。
